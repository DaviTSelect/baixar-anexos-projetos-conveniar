# v1.1.0 — Interface e fluxo completo

**Data:** 2026-09-17
**Commit:** `bcaa0d9` (mesma base da v1.0.0 — tag aplicada ao mesmo commit)

## O que mudou em relação à v1.0.0

Esta tag foi aplicada ao mesmo commit da v1.0.0, consolidando o nome de versão
após refinamentos de nomenclatura. Os arquivos incluídos são idênticos à v1.0.0.

### Destaques do conjunto desta versão

- Interface gráfica com customtkinter operacional
- Autenticação via `.env` sem campos de login no painel
- Download organizado em `downloads/<projeto>/<contrato>/`
- Verificação de atualizações ao abrir o aplicativo

## Limitações conhecidas nesta versão

- Paginação não implementada
- Seletor `imgLoad` do loader ainda não validado no Conveniar
- Contratos sem tabela de anexos podiam interromper o processamento
