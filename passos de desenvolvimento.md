# Roteiro de estudo

1. Leia o [README](README.md) para entender o objetivo, a configuração e a execução.
2. Consulte o [guia técnico](docs/desenvolvimento.md) e acompanhe o código na ordem `src/main.py`, `src/launcher.py`, `src/interface.py` e `src/browser.py`.
3. Use a [matriz de testes](docs/testes.md) para distinguir o que foi simulado das validações ainda necessárias no Conveniar.
4. Para colaborar, siga o [guia de Git e GitHub](docs/github-basico.md) e as [orientações de versionamento](docs/versionamento.md).

Este roteiro não altera as regras de consulta ou autoriza publicar versões.
